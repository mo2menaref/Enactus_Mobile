# 🚀 Enactus Member Task Manager - Flutter & Cloud Firestore

A clean, responsive, and real-time Task Management Application built with **Flutter**, **Dart**, and **Firebase Cloud Firestore**. Designed and developed as part of an intensive Flutter development curriculum for the **Enactus IT & Mobile Development Team**.

---

## 📌 Important Note on Repository History

> **Notice:** Git commit tracking for this repository begins from **Session 6 (Full CRUD Integration & Persistence)**. The foundational UI layouts, basic navigation, and initial static state experiments built during Sessions 1–5 were consolidated into the baseline structure upon pushing to GitHub.

---

## ✨ Features

- 👤 **Multi-User Sync:** Enter a username to load and manage cloud-synced task lists for specific members.
- 🔄 **Real-Time Reactive Updates:** Powered by `StreamBuilder` and Cloud Firestore `snapshots()`. Tasks update instantly across devices without manual refresh or `setState()`.
- ➕ **Create Tasks:** Form-validated task creation specifying Task Name and Assignee.
- ✏️ **Update Tasks:** Edit a task's name via an interactive dialog and toggle its completion status (`isDone`) with instant sync.
- 🗑️ **Dual Deletion System:**
  - **Swipe-to-Delete (`Dismissible`):** Drag task items horizontally with a custom red delete background.
  - **Manual Action Button:** Dedicated delete icon on each card.
  - **Confirmation Dialog:** Every deletion (swipe or button) is confirmed via an `AlertDialog` before it happens.
- 🏗️ **Clean Architecture:** Strict separation of data models, UI screens, and network/database services.

---

## 🛠️ Tech Stack & Architecture

- **Framework:** Flutter (Dart)
- **Database:** Firebase Cloud Firestore (NoSQL Document / Sub-collection store)
- **State Management & Async:** `StreamBuilder`, `Future`, `Stream`, reactive state handling
- **Key Flutter Packages:** `cloud_firestore`, `firebase_core`, `shared_preferences`

## 📊 Database Structure (Cloud Firestore)

Data is organized using a hierarchical Collection / Document / Sub-collection schema:

```text
users (Collection)
 └── {username} (Document)
      └── tasks (Sub-collection)
           └── {taskId} (Document)
                ├── taskName: String
                ├── assignedTo: String
                ├── title: String
                ├── isDone: Boolean
                └── createdAt: Timestamp
```

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (v3.0.0 or higher)
- Dart SDK (^3.11.4)
- Android Studio / VS Code with Flutter extensions
- An active Firebase project

### Installation & Setup

**1. Clone the repository:**

```bash
git clone https://github.com/your-username/enactus-task-manager.git
cd enactus-task-manager
```

**2. Install dependencies:**

```bash
flutter pub get
```

**3. Configure Firebase:**

Add your `google-services.json` (Android) or `GoogleService-Info.plist` (iOS) to the respective platform folders, or configure via the FlutterFire CLI:

```bash
flutterfire configure
```

**4. Run the app:**

```bash
flutter run
```
